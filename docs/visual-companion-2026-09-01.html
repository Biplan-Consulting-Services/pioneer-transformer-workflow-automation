What changed

The file stopped being the system

Until this morning, FRM10-12 was the database. Location, Status, Tank, Frame, Core Status, Coil Winder, the tanking and delivery dates — all of it was typed straight into the workbook and existed nowhere else. One person at a time, and a bad refresh could take the day's work with it.

The data has moved out into a SharePoint list. The workbook is still there, still looks the same, still sits at the same address on the server — but it now rebuilds itself from SharePoint instead of holding the only copy. That last detail is what keeps FRM09, BO Manager and the Power BI reports working with no change at all.

Day to day

What actually changes for you

  Until yesterday From this morning
Finding your work Scroll the workbook and filter it down by hand. The Production Floor view — grouped by Location, each step its own colour, the most urgent unit at the top of every group.
Updating a unit Open the file, find the row, type, save, hope. Click the cell. Type. Move on. No save button and no refresh — it writes as you go.
Working at the same time One person at a time. “Someone else has it open.” Everyone at once. Your change appears on everyone else's screen straight away.
Losing a day's typing A crash or a mistimed refresh could take it. It happened in August. Every edit is saved as it is made, and the list keeps its own version history.
The layout you know The workbook's columns were the only layout there was. The Planning view — the workbook's collapsed layout, same columns in the same order. The detail columns you would expand to reach are all in All Items.
A new order Nothing created the unit rows. They only appeared inside the workbook, after a refresh. Sales hits Save and the unit rows create themselves, ready to track.
The Excel file Where the data lived. A mirror. Look at it all you like — don't type in it. Anything typed there is wiped on the next rebuild and never reaches SharePoint.
Live now

What's running this morning

Order Items

One row per unit, live in SharePoint. This is the database everything else now reads from.

Production Floor view

Grouped by Location — Bobinage, Assemblage, Four, Finition, Livraison and the rest. Delivered and cancelled units drop off on their own.

Planning view

The workbook's collapsed layout — the column set you already work in, same order. The detail columns live in All Items.

The site home page

One place to start, with links to both views and a short how-to guide in French and English.

Order fan-out

New in this release. Saving an order in the sales app creates every unit row, including the SA units, with no one typing them.

FRM10-12 as a mirror

Rebuilt from SharePoint, read-only, at the same address as before — so FRM09, BO Manager and the Power BI reports carry on untouched.

What's coming

The rest of it, in order

Today moves production tracking. Four things follow it, and they are sequenced because each one leans on the one before.

  1. This week

    The cleanup pass

    Some units that have already been delivered or cancelled are still showing as active, and a handful of dates carried over wrong from the old workbook. A reconciliation pass finds them against the archive and retires them. Nothing anyone needs to do by hand.

  2. Next build — fully specified

    Workflow Tasks

    Automates the front of the order process — customer PO, order entry, the electrical and mechanical preliminary reviews running in parallel, planning schedule, work order, and confirming the planned dates with the client. Each step notifies whoever's turn it is, by email and Teams. This is the answer to the other standing complaint: nobody can see whose turn it is on an order.

  3. Agreed August — pending access

    Monday.com as the working layer

    The production team moves onto Monday day to day, with the stage-advance logic living there. Order Items stays the database underneath it — it is what reporting runs against and what the rest of the workflow cross-references. The SharePoint stage-stamping automation was switched off tonight in anticipation, and a disabled copy is parked, so it can be turned back on in one click if Monday doesn't work out.

  4. Designed, not built

    Drawings and NC records

    A document library that routes each engineering drawing to the production step that needs it — replacing the file server, the multiple printed copies and the colour-coded folders, with the goal of a shop-floor tablet pulling up the right drawing when a task starts. Alongside it, somewhere to put non-conformance photos and notes against a specific unit and step. There is nothing like that today.

  5. Ongoing

    Archiving

    Completed and cancelled orders move out to the Excel archive on a schedule, so the live lists stay fast as the years add up rather than growing forever.

If something looks wrong, come and ask.

A unit missing, a column empty, anything that just doesn't seem right — don't work around it and don't guess. It is a new system and finding the rough edges early is genuinely useful.
