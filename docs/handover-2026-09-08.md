## How to work on the flow — use the tooling, do not hand-edit

**Never touch the Power Automate UI.** I get stuck in it, repeatedly: 45-second `document_idle`
timeouts, the designer canvas will not render this flow at all, and deep-linking the flow page
fails because the session lacks the environment context. SharePoint is fine to work with
directly, including creating columns. See `feedback_ask_before_touching_tenant` in memory.

The loop that works, per `Workflow-Automation/CLAUDE.md`:

```
user copies the flow JSON out of the designer  ->  _inbox/
flow_version.py intake                          ->  a `pulled` version; _inbox archived
<one apply_*.py per change>  +  snapshot --local ->  a `local` version, parent = that pull
flow_version.py stage vNNN                      ->  _outbox/PASTE-ME.json
user pastes it back, saves, copies out          ->  _inbox/
flow_version.py intake                          ->  hash matches => `applied`
```

`flow_version.py status | list | diff A B | stage | intake | emit`. **`_outbox` is empty right
now, which is correct — v006 is live and there is nothing to paste.**

Rules that are load-bearing, all learned the hard way today:

- **`applied` is inferred, never asserted.** A local version flips only when a later pull carries
  the same definition hash. A paste cannot prove itself.
- **Author locally, validate locally, paste once.** Each `apply_*.py` asserts its own diff and
  **refuses to emit** a definition that does not match its intent. That is not ceremony — it
  caught two bugs in v006 that a per-field review looked clean through:
  `UpdateOrderItem`'s `id` still read a deleted action (**every update would have failed**), and
  the model-revision resolution still read another (**every revision would have been null**).
- **Keep the `.zip`.** It is the only artifact that re-imports — it carries
  `connectionsMap`/`apisMap`, which rebinds the connections. A definition-only JSON cannot
  restore a flow. **JSON for editing, `.zip` for rollback.**
- **Milestone exports:** the user offered to export at each milestone for review. Take it. The
  next natural one is after `R4` verifies, before `R7`.

## The tracker artifact — fixed 2026-09-08

The risk register at
`https://claude.ai/code/artifact/a787ce02-c396-4626-ae79-67a27fe50130` was rendering as
**unstyled text with the dependency graph collapsed into a column**. **Diagnosed, fixed and
republished** — it renders again, with the corrected statuses.

It was **not** the Preview/Code toggle, and **not** the nesting corruption. The live version had
**zero `style` blocks** — no `title`, no font links, no `app-state` element either: lines 2–259 of
the good local copy, one contiguous span, **13,339 bytes of CSS**. Everything else was
byte-identical, so no live edit was lost. With `app-state` gone, `STATE` parsed to `{}` and **every
step read `todo`** whatever the real progress.

**Root cause — two contracts that are exact opposites.** The **Artifact tool** takes a *body
fragment* and adds the skeleton; the in-page **`publish()`** runtime API takes *a complete
document, doctype first*, and explicitly says never to serialize the live DOM. `serialize()`
returned `document.body.innerHTML`, violating both. Silent and cumulative: this page's `title`,
font links and `style` are authored at the top of the body, a fragment publish **normalises them up
into the head**, and the next save — reading the body alone — no longer saw them. **Two clicks did
it**, with no error. The earlier 3-doctype nesting bug was the same error from the other direction;
"fixing" it by going body-only just traded one failure for this one.

`serialize()` now assembles a complete document, gathering the page's assets by `data-asset` marks
wherever they sit. **Verified as a fixed point** over four generations in jsdom — load, click,
save, reload — with CSS steady, ticks persisting, and exactly one of each shell tag. The mechanism
and the two load-bearing subtleties are written up in `artifacts/README.md`; read that before
editing the page, because one of them will silently re-break it.

**Canonical source is now `artifacts/risk-register-tracker.html`** — a body fragment. Edit it and
republish **passing the URL**. `risk-register-tracker-recovery-2026-09-08.html` is kept only as the
provenance snapshot; it has a document wrapper for local viewing and must not be published as-is.
