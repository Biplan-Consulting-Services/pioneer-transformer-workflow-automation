R12The nightly refresh can reintroduce the day-early bug it exists to avoidhalf closed

Half closed 2026-09-05. The test column proves SharePoint accepts TODAY(), so the design survives. FixCheck the test column after 8pm Eastern: if it shows tomorrow, TODAY() is UTC and every evening edit drifts.
